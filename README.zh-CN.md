# Codex 驾驶舱

Codex 驾驶舱是一款本地优先的 macOS 小工具，用更轻量的方式查看额度状态和每日用量，不把一次查看变成一整块复杂的仪表盘。

> Codex 驾驶舱是独立的社区项目，不是 OpenAI 官方产品，也不隶属于 OpenAI。

## 它能做什么

- 展示服务方返回的额度快照、本周剩余、每日用量、个人每日上限和重置时间。
- 把最重要的状态放进紧凑胶囊，点击后再展开完整驾驶舱。
- 根据胶囊所在的屏幕边缘和角落向内展开，让展开窗口尽量贴近原位置。
- 支持浅色、深色和跟随系统主题，支持中文与英文，支持调整字级，并可在后台运行而不占用 Dock。
- 在本地历史足够完整时，用日历查看每日用量和舒适度记录。
- 提供外部重置预测的快捷入口，但不会把外部服务的数据混进本地额度计算。

## 隐私优先

Codex 驾驶舱的设计目标是让个人用量数据留在本机：

- 不读取聊天正文、提示词或对话历史。
- 不保存服务方原始 token。
- 不操作账户、不兑换额度，也不修改服务方设置。
- 每日历史由本地可用的额度快照和重置边界推算；数据缺失、过期或格式不兼容时，会明确显示不可用，不静默编造数字。
- 个人上限和规划滑条只是本地显示与规划偏好，不是服务方的硬限制。
- 项目设计中不包含独立的遥测或账户数据上传。

服务方返回格式可能变化。界面上的数字应理解为带有来源和覆盖边界的快照，而不是账单或官方审计结果。

## 当前状态

仓库目前保持私有，正在准备公开发布。项目准备完成后再发布源码、签名构建包和版本说明。

## 从源码构建

首次公开发布前会补齐公开源码目录。预计的开发命令如下：

    cd apps/quota-float
    npm install
    npm test
    npm run build
    npm run tauri build

原生构建需要当前版本的 Node.js、Rust stable，以及 Tauri 2 所需的平台依赖。
