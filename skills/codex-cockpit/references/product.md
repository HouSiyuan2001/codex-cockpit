# 产品答疑入口

完整[产品说明书](https://github.com/HouSiyuan2001/codex-cockpit/blob/main/docs/USER-GUIDE.md)位于源码 docs/USER-GUIDE.md。Skill 独立安装后不一定包含源码；能访问时读取对应 Release/commit 的说明，不能用最新 main 对旧包作保证。暂时无法访问时使用以下边界，并明确版本细节未核实。

- 驾驶舱是独立社区桌面工具，不是 Codex 本身。看官方额度、历史 Token/模型/任务、估算成本、日历、计划、体验及 PNG 小票。
- 额度、Token 和估算金额不是同一份数据；金额不是官方账单，缺价不是零，计划/第三方预警不保证额度重置。
- Mac 通用 DMG，Windows x64 安装器，实际平台与签名状况看 Release。普通用户不必安装 Rust/Node；首开与实际进程版本仍需验证。
- 本机使用无需同步服务器；仍可能查询供应商额度、第三方预警和版本更新，不宣传为完全离线。
- 云同步可选，一个管理员用自己的 Cloudflare 账户自建 Worker/D1，普通成员只接邀请。每空间最多 32 台设备，面向可信小团队，不是作者提供的公共服务。
- 用量、显示名称、设备 ID、归属、计划与体验可被空间成员及服务器管理员读取，不是端到端加密。任务名称/标识默认不共享。采集读取历史文件提取用量，但客户端不上传对话正文、登录凭据或项目路径。
- 设备 ID 代表电脑，组员代表人；沿用本机 ID，一台电脑归一人，一人可有多台电脑，不复制身份令牌。
- 每分钟接收、约五分钟采集上传可能因离线/扫描延迟。一次立即同步要验证新的上传和对方接收时间，不用缓存证明成功。
- 关闭同步不删数据，关闭任务分享需下次成功上传才从新快照移除。owner 的设备停用入口阻止后续访问，仍保留快照/缓存/备份；完整删除及恢复需管理员确认处理。
- 429 等待至少一分钟；503 可能缺限流绑定。不要无休止重试、换陌生服务、清空配置或关闭系统保护。
- 咖啡支持完全自愿，不影响功能。作者主动公开收款码，不把它误当需要清理的凭据。

对不在已核实功能范围的请求明确说明未知或未实现。只回答“怎么用”时不执行安装/上传/部署；排障读取 references/troubleshooting.md，安装读取 references/install.md，管理员部署定位 Cloudflare Skill。
