# Contributing

Follow `AGENTS.md` and the desktop SOP. Preserve read-only provider access, explicit opt-in sync, missing-data indicators and revision conflicts. Include behavioral regression tests.

Use synthetic people/tasks/devices. Do not add local home paths, credentials, live account IDs, personal endpoints or exports. Run the test matrix/publication audit and declare asset licenses.

Making the repository public is a separate maintainer decision. No automation should change visibility.
