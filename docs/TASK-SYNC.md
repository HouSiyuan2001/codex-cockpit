# 跨设备任务用量（0.2.18-p020.34）

已加入 Cloudflare 共享空间的设备上传 `taskUsage.version=1`：任务 ID、标题、父/根 ID、关系、每日 Token 和已知成本，以及模型汇总。不上传项目名称/路径、消息正文、Agent 角色或凭据；任务标题本身会向空间成员共享。

任务自用量先按设备分别聚合，只在同一设备内部折叠已证实的子 Agent；普通 fork 保持独立。显示身份为设备 ID 与任务 ID 的二元组，重复设备取最新快照，本机云端回声不与本机采集重复累加。组员和时间筛选同时作用于圆环与列表，已知部分成本参与降序排序及圆环，未知不当成零成本。

非本机任务在标题下标注 `来自 <设备名>`。只读取当前云端成员名单中的缓存，离线时仍显示最后收到的快照；退出/撤销成员不会因遗留文件继续展示其任务。

旧客户端兼容设备总量，但没有任务明细，须升级后上传。首次历史补扫、源数据缺失及传输容量上限会产生部分任务快照：单次最多 4000 个任务，优先最近活跃任务，整个用量快照预留在约 900 KB 内；超限任务不截断其日账，直接标记 partial，UI 统计说明提示只计已接收明细。因此“全部时间”指现有可读任务记录，不保证完整历史恢复。设备总账和任务明细的扫描时点、覆盖范围可能不同，不能用总账填造任务用量。

此版本只扩展 Cloudflare 传输，不向旧 Git 同步自动上传任务标题。跨时区日界仍沿用来源设备日账，未实现 UTC 重分桶。
