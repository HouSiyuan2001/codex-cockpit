# 舒适反馈按体验日期加权

## 新反馈更能代表现在的体感

拟合沿用原有有序分类似然、K与舒适带先验，但每条反馈的对数似然乘以权重：

`w = coverage × 2^(-ageDays / 14)`。

coverage为完整观测1、部分观测0.75；没有用量观测的反馈仍不参与拟合。ageDays按反馈localDate（体验日期）与当前本地日历日期的差计算，避免夏令时造成23/25小时的偏差。补写/编辑旧反馈的observedAt不会使旧体验恢复新权重。未来或无效日期不参与当天拟合，但不删除存储中的记录。

14天半衰期是本地启发式默认值，不是Codex版本或升级周期的估计：今天为1、14天前为0.5、28天前为0.25。参数集中在COMFORT_FEEDBACK_HALF_LIFE_DAYS，便于后续调整；本轮不新增设置滑条或自动读取Codex版本。

## 权重同时影响K、信心和点的显示

权重预先计算一次，再用于全部K/舒适带候选。信心的样本量因子使用权重之和，不再用未衰减的原始条数；该和展示为“加权样本”，并非Kish有效样本数或正式统计置信度。其他集中度计算与保守先验保留，因此长期无新反馈时证据减弱，而非一直维持旧信心。

原始样本数保留，旧点变淡但可见，点标题显示日期与拟合权重。图注显示14天半衰期。现有30秒规划时钟会触发重新计算，因此跨日无需重启；日期权重一天内不变。

## 数据与兼容性

v4拟合模型兼容v3、v2、v1反馈记录；持久化记录格式继续使用v3，避免回退旧应用时不认识新版本号而丢记录。不删除或改写原始体感、用量、日期。现有90条存储上限未改动。本轮只改变本地拟合解释，个人手动上限、账户接入和窗口动画未改动。
