# 当前余额与自然重置规划

新本地策略使用官方周额度余额 R、距官方自然重置的精确天数 D、今天剩余比例 h、今天已观测使用 U、个人拟合 K 和提前重置风险 p（0–1）。使用日沿用北京时间 04:00 分界。

- 均匀分配：A = R × min(1, h / D)。D 不取整、不额外加一天。
- 风险加成：B = (R − A) × p² × h。
- 今日疲劳余量：C = max(0, K × (1 + 1.5p) × 周末系数 − U)，周末系数沿用 0.75，其他日为 1。
- 今天还建议用：min(R, A + B, C)。今日总建议 = U + 今天还建议用。

所有百分比均占完整周额度。余额已经包含历史消费结果，因此不再另加昨日结转。每日总建议和“今天还建议用”分别展示，防止重复扣除今天已用。自然重置时间缺失或已经过期时不生成此策略建议，等待新的官方快照；不会自动认定余额已经恢复。

## 消耗紧迫度与重置风险热图

横轴为消耗紧迫度 q = R / D（周额度百分比/天），纵轴保留提前重置风险 0–100%，颜色为今天还建议使用的量。余额越多或自然重置越近，q 越大；例如80%/4天=20%/天、80%/2天=40%/天。q 可以超过100%/天，它是速率而非余额；横轴默认0–100，超出时扩展至覆盖当前点，不截断输入。

热图是当前余额 R 下的条件切片：K、R、今天已用和今天剩余时间固定，每格以 q 与风险 p 调用同一个规划函数（用 D=R/q 还原时间）；当前点使用实际 R/D 和实际风险。q=0 采用无限时间极限；余额0时建议始终0。保持当前余额可避免将相同速率、不同余额的情景错误地当成同一可花总量。实际快照缺失/到期时不绘制假当前点。

均匀分配亦可写为 A=min(R,q×h)，与上式完全等价；本次恢复风险纵轴不更改既有实际建议算法。

疲劳上限可能使临近重置仍留有余额，这是保留的个人舒适约束。该启发式策略不是全局产出最优化器，提前重置风险不是自然重置天数。旧公开网站示例函数保留用于历史回归，当前驾驶舱调用新策略。
