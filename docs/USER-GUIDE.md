# Codex 驾驶舱产品说明书

这份说明给使用者，也给协助安装和回答问题的 AI。实际界面、版本和 Release 说明优先于旧文档；不要把官网示例数据当成用户的真实统计。

## 它能帮你做什么

驾驶舱是独立的 Mac / Windows 桌面工具，不是 Codex 本身，也不是 OpenAI 官方产品。悬浮窗显示当前登录账号的额度、重置时间和使用计划；控制中心可以按成员、任务、模型和日期查看 Token 与估算成本，还能查看日历、记录使用体验、把选中任务导出为 PNG 小票。

“官方剩余额度”“本机历史 Token”“估算金额”来自不同链路。Token 不等于额度百分比，估算金额不是订阅账单。GPT‑6.1 Sol 已有默认计价和别名识别；统一价格表或本地覆盖优先，未知模型仍保留缺价提示。具体价格与估算规则以当前版本和空间价格表为准。

## 安装与第一次打开

从[项目 Releases](https://github.com/HouSiyuan2001/codex-cockpit/releases)选 Mac 通用 DMG 或 Windows x64 安装包，核对同一版本的 SHA‑256 校验表。预发布版不一定出现在 latest 页面。普通使用者不需要安装 Node.js、Rust 或部署服务器。

更新前保留旧应用和本机配置。系统密码、GitHub/Cloudflare 登录、钥匙串授权由你亲自处理，不发送给 AI。Mac 公证和 Windows 发布者签名是否具备，以该版本说明为准；不要关闭 Gatekeeper、SmartScreen 或 Defender。

启动后先确认实际安装版本和应用路径，再打开控制中心。本机 Codex 正常登录后才能查询官方额度；首次采集历史可能需要等待，未登录、缺少历史或部分数据都应保留真实状态，不造数据补齐。

详细步骤见[安装指南](../skills/codex-cockpit/references/install.md)。安装 App、安装 AI Skill、部署服务器是三件独立的事。

## 日常怎么用

1. 点开悬浮窗进入控制中心，默认进入“用量”。切换 Token / 成本、成员和时间范围，先确认筛选条件再比较数字。
2. 在设置中的“组员与设备”设置设备归属。一台设备只归一位成员，一位成员可以有多台电脑。“默认查看谁”只是默认筛选，不改变设备归属。
3. 在日历中查看对应日期的用量；没有记录不代表零用量。日历/共享计划沿用 UTC+8 口径，历史账本还受采集设备时区影响；任意跨时区历史重分桶尚未实现。
4. 在额度/计划相关页面调整今天的安排，记录紧张、合适或宽裕的体验。个人手动计划不能拿来覆盖另一个人的分配。
5. 选择任务生成小票，复制 PNG 后粘贴到本机图片应用检查。小票可能包含任务名称，发送给别人前自己确认。

重置预警来自第三方社区数据，不是 OpenAI 的承诺，也不保证何时重置。驾驶舱不能增加官方额度或替你登录其他人的账号。

## 云同步：先决定你是哪种用户

**只看本机：** 不需要 Cloudflare，保持云同步未配置即可。应用仍可能向模型供应商查询额度、读取第三方预警和检查更新；“本机使用”不等于完全离线。

**加入已有团队：** 向你信任的管理员获取服务地址和邀请码，在“控制中心 → 设置 → 云同步 → 接受邀请”填写。沿用本机原有设备 ID，首次接入可用自动生成值；不要用别人的设备 ID 或身份令牌。普通成员无需 Cloudflare 账号，也不应另建共享空间。

**管理员自建：** 一个管理员在自己的 Cloudflare 账号中部署 Worker + D1，配置限流和建站密钥，在第一台电脑创建空间，再邀请其他设备。项目作者不代管公共同步服务器；各团队自己的管理员负责数据、权限、备份和费用。具体步骤见[自部署指南](../skills/cloudflare-sync/references/self-hosting.md)。

这个服务面向互相信任的小团队，不是开放注册的公共 SaaS。单空间最多 32 台设备。成员可查看共享数据，并修改组员归属及共享计划；个人手调有身份限制，邀请和统一价格由 owner 管理。

## 会共享什么，谁能看到

同步包含显示名称、设备 ID、归属、按日/模型聚合的 Token 与估算成本、计划和已归属的体验记录。任务/项目名称与任务标识默认不共享，只有主动开启才上传。客户端不把原始对话正文、提示词、项目路径或模型账号凭据加入同步载荷。

本机采集会读取可能含对话的会话文件来提取用量，不能理解成“从不读取历史文件”。同一空间的成员和 Cloudflare 管理员能读取共享内容，数据不是端到端加密。

关闭任务共享后，要等下一次成功上传才从新快照移除明细；已经下载的缓存、图片、备份不会自动撤回。关闭自动同步不是删除云端数据。owner 可在“云同步 → 设备访问权限”确认停用其他设备；停用阻止后续访问，不删除历史或撤回该设备已获取的数据。

## 怎么判断同步真的成功

接收约每分钟检查一次，采集上传约每五分钟；休眠、网络和扫描耗时会延迟。点“立即同步”会上传本机数据，不是只读检查。

验证时分别看最近采集、成功上传和接收时间；检查另一台设备收到本次的新快照、组员归属及共享配置版本。A 改归属后 B 能收到，B 改后 A 能收到，才说明双向配置正常。旧缓存、health 返回正常或“已连接”都不能单独证明同步成功。

遇到 429 先等待至少一分钟，不连续点击重试；503 可能是管理员升级后忘了配置限流绑定。不要为了排障向陌生服务器上传。

## 常见问题

- **有 Token，没有金额？** 检查成本模式、时间范围、模型名称、共享价格表及部分数据标记。未知成本不是零，历史 Token 也不足以恢复精确上下文计价。
- **怎么找不到窗口？** 先看悬浮窗、菜单栏/托盘和运行进程；它不是普通 Dock 主窗口。别直接删设置。
- **另一台电脑没更新？** 核对相同服务/空间、自动同步状态和各自上传/接收时间。任务标题不出现，也可能只是对方没有开启分享。
- **邀请码失效？** 让 owner 重新生成，经可信渠道传递并在 App 中填写，不贴到 Issue 或 AI 对话。新邀请默认 24 小时、单次使用。
- **停用后怎么恢复？** 联系管理员按[维护指南](../skills/cloudflare-sync/references/maintenance.md)确认身份后处理；不能复制另一台机器的凭据。完整账号删除、全量令牌轮换及备份清理仍需管理员操作。
- **能让我多用一些官方额度吗？** 不能。计划、成本和预警只是参考。
- **咖啡钱是必须的吗？** 完全自愿，不影响任何功能。收款码是作者有意公开的支持入口。

更多排障见[按现象排障](../skills/codex-cockpit/references/troubleshooting.md)和[隐私说明](PRIVACY.md)。提交问题时仅提供版本、平台、步骤和脱敏错误；不附登录文件、邀请码、钥匙串内容、原始会话或完整数据库。
