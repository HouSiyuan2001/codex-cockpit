# Codex 驾驶舱 · v0.3.6

- 今日总建议改用 Codex Resets 近期直接刷新额度的记录。越新的记录权重越高，提前重置风险越高，建议越倾向于把额度安排到今天。
- macOS、Windows 和 Linux 使用同一套计算方式。

下载：Mac 选 `universal.dmg`，Windows x64 选 `x64-setup.exe`，Linux x64 选 `.AppImage` 或 Debian/Ubuntu 的 `.deb`。校验文件见 `SHA256SUMS`。

Mac 未公证，Windows 无发布者签名；Linux 原生 Wayland 和混合 DPI 仍待完整验证。
