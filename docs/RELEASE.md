# Codex 驾驶舱 · v0.3.7

- 在设置中开启 Claude，即可切换 Codex、Claude 和双胶囊视图。新安装默认关闭 Claude。
- Claude 驾驶舱和 AI 双卡显示周重置倒计时，Claude 还显示 5 小时重置倒计时。
- Claude 铃铛只提醒最近 48 小时的公告，点一下可打开原帖。今日建议默认按账户额度和周重置时间计算。
- Claude 本地用量支持日历、趋势和 API 参考成本。参考成本仅供估算。
- 修复双胶囊右侧裁切和 Windows 窗口展开时的圆角、位置问题。

下载：Mac 选 `universal.dmg`，Windows x64 选 `x64-setup.exe`，Linux x64 选 `.AppImage` 或 Debian/Ubuntu 的 `.deb`。校验文件见 `SHA256SUMS`。

Windows 无发布者签名。Linux 的 `.deb` 需手动更新。
