# Codex 驾驶舱 · v1.0.1

- 控制中心的「额度」改为「Codex 配速」，直接显示配速图和舒适曲线。Claude 和 Gemini 仍可在「用量」中切换。
- 切换 AI 时保留上一次选择的统计时间范围。
- 改善三家额度的到期刷新。需要时可在设置中开启「5h 到期补刷」，该选项默认关闭，开启后可能消耗少量额度。
- Codex 没有 5 小时额度时，菜单栏显示本周剩余。新安装默认只开启 Codex，升级保留已有选择。

### 下载

- Mac 通用版选 `universal.dmg`。
- Windows x64 选 `x64-setup.exe`。
- Linux x64 选 `.AppImage`，Debian 或 Ubuntu 也可选 `.deb`。
- 安装包校验值见 `SHA256SUMS`。Linux 的 `.deb` 需手动更新。
